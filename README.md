# 🌸 Cyclus — Period Tracker

A beautiful, cross-platform (iOS + Android) period tracker built with Flutter
and Firebase. Adaptive predictions for both **regular** and **irregular**
cycles, with a calendar view, daily symptom/mood log, insights charts, and
gentle reminders.

---

## ✨ Features

- 🌷 **Today screen** with circular cycle ring, current phase chip, quick stats
- 📅 **Calendar** with color-coded period / fertile / ovulation / predicted days
- 📊 **Insights** — cycle-length chart, average period/cycle, regularity score
- 💧 **Period logging** — start/end with one tap
- 📝 **Daily log** — flow, symptoms, mood, free-text notes
- 🔔 **Local notifications** — period reminder, fertile window, daily log nudge
- 🔐 **Firebase Auth** — email/password + Google sign-in
- ☁️ **Firestore sync** — your data follows you across devices
- 🎨 **Beautiful UI** — soft pinks & lavenders, Poppins font, rounded cards

## 🚀 Setup

### 1. Prerequisites
- [Flutter SDK 3.19+](https://docs.flutter.dev/get-started/install)
- Android Studio (for Android builds) and/or Xcode (for iOS)
- A [Firebase project](https://console.firebase.google.com/)

### 2. Generate platform folders

This repo contains only `lib/` source. From the `period_tracker/` directory:

```bash
flutter create .
flutter pub get
```

`flutter create .` will fill in `android/`, `ios/`, `web/`, etc. without
touching your `lib/` files.

### 3. Wire your Firebase project

```bash
dart pub global activate flutterfire_cli
flutterfire configure
```

Choose your Firebase project and select Android + iOS. The CLI overwrites
`lib/firebase_options.dart` and drops:
- `android/app/google-services.json`
- `ios/Runner/GoogleService-Info.plist`

In the Firebase console:
- **Authentication** → enable **Email/Password** and **Google** providers
- **Firestore** → create a database in production mode and apply these rules:

```js
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
      match /{document=**} {
        allow read, write: if request.auth != null && request.auth.uid == uid;
      }
    }
  }
}
```

### 4. iOS extras
Add to `ios/Runner/Info.plist`:

```xml
<key>NSUserNotificationUsageDescription</key>
<string>We send gentle reminders before your period and fertile window.</string>
```

Add the Google sign-in reversed client ID (from `GoogleService-Info.plist`)
to `CFBundleURLSchemes` per the
[google_sign_in iOS guide](https://pub.dev/packages/google_sign_in#ios-integration).

### 5. Android extras
The `flutterfire configure` step writes `google-services.json` and updates
gradle files automatically. Min SDK should be **23+** (set in
`android/app/build.gradle`).

### 6. Run

```bash
flutter run                  # auto-pick attached device
flutter run -d chrome        # web preview
flutter build apk --release  # Android release
flutter build ios --release  # iOS release (requires macOS)
```

### Firestore data model
```
users/{uid}
  ├── (UserProfile fields)
  ├── cycles/{cycleId}     → Cycle
  └── logs/{yyyy-MM-dd}    → DailyLog
```

### Prediction algorithm
- Collects up to the last 6 completed cycles
- `averageCycleLength` = rolling mean
- `isIrregular` = standard deviation > 7 days
- `nextPeriodStart` = lastStart + averageCycleLength
- `ovulationDay` = nextPeriodStart − 14 (luteal phase length)
- `fertileWindow` = [ovulation−5, ovulation+1]
- `confidence` blends sample size and stability (20–99)

All logic lives in `lib/services/prediction_engine.dart` as pure functions —
easy to unit-test.
